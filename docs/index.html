Terminal UX, upgraded

One command palette for every AI CLI you use.

tuai gives Claude, Cursor, and Antigravity a shared, searchable interface so you can stop memorizing provider-specific command syntax.

Install from npm View source 
$ npm install -g @nire0510/tuai
$ tuai claude

provider: claude
tab: Commands
search: /code review

selected: /review --focus reliability

Unified command discovery

Browse commands, flags, and slash commands in one navigable catalog.

Fast command building

Compose executable CLI commands with live search and keyboard-only flow.

Provider-aware catalog

Switch contexts instantly between Claude, Cursor, and Antigravity.

Quick workflow

  1. Launch a provider: tuai claude or tuai cursor.
  2. Search by typing / and filter commands or flags.
  3. Press Enter to append selections to your command buffer.
  4. Press X to execute instantly.

Built for people who live in the terminal.
